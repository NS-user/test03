2使った技術・学んだ概念

🎨Canvas 2D ドット絵

画像ファイルを使わず、fillRectで1ドットずつ描くプログラム生成スプライト。色だけ差し替えて陣営を表現。

🧭BFS（幅優先探索）

ユニットの移動可能範囲を探索。地形ごとの移動コストや壁・敵ユニットを考慮して到達マスを計算。

⚔️戦闘計算と相性表

攻撃力×HP割合×兵種相性×地形防御でダメージを算出。反撃や撃破判定も。

📡電子戦（ジャミング）

範囲内の敵の攻撃力と移動力を低下。距離判定（チェビシェフ距離）で影響圏を表現。

🔐暗号戦（暗号化/復号）

拠点に暗号レベルを持たせ、復号で占拠可能に、暗号化で防御。勝利条件の核に。

🤖敵AI（ヒューリスティック）

各ユニットが「攻撃で得な相手→拠点占拠→前進」を評価して行動を選ぶ簡易思考。

🚀GitHub Pages + Actions

プッシュで静的サイトを自動デプロイ。.github/workflowsのYAMLで定義。

📱レスポンシブCSS

@mediaで画面幅880px以下は縦積みに。canvasをmax-width:100%で画面幅にフィット。

3つまずき と 解決（ここが学び）

問題: 敵AIが毎ターン全拠点で生産し、5ターンで23体に増殖して手がつけられない。
解決: 生産に総数の上限と1拠点あたりの生産確率を導入。盤面が溢れないよう調整した。
問題: GitHub Pagesの自動有効化が Resource not accessible by integration で失敗。
解決: ActionsのトークンにはPagesサイトを新規作成する権限がないと判明。設定でPages(Source: GitHub Actions)を一度だけ手動で有効化 → デプロイ成功。
問題: スマホで開くとマップが真っ黒。
解決: 横並び固定幅(660px)レイアウトのせいで、狭い画面だとcanvasが情報パネルに押し出され切れていた。レスポンシブ対応で縦積み＋幅フィットに修正。

4理解度チェック（クイズ）

0 / 5 問オープン
Q1. 参考にした「成金大防衛」はどんなジャンルのゲーム？
拠点を奪って資金を稼ぎ、ユニットを量産して敵の首都（全拠点）を制圧する ターン制の戦略シミュレーション。今回はこの「拠点制圧→収入→生産」のループを下敷きにした。
Q2. 「暗号大戦線」で敵中枢AI(KRONOS)を制圧するには何が必要？
敵コアは3重に暗号化されているので、まずクラッカーで復号(暗号Lv3→0)し、その後にボットで占拠する。暗号戦が勝利の核になっている。
Q3. 電子戦機（ジャマー）の効果は？
周囲の範囲内にいる敵の攻撃力と移動力を低下させる。範囲判定にはチェビシェフ距離（縦横斜めを同じ1マスと数える）を使った。
Q4. GitHub Pagesのデプロイが最初に失敗した原因は？
ワークフローの GITHUB_TOKEN にPagesサイトを新規作成（有効化）する権限がなかったため。設定画面でSourceを「GitHub Actions」にして一度だけ手動で有効化したら成功した。
Q5. スマホでマップが真っ黒に見えたのはなぜ？どう直した？
横並び・固定幅660pxのデスクトップ前提レイアウトで、狭い画面ではcanvasがサイドパネルに押し出されて切れていたから。@mediaで縦積みにし、canvasを画面幅にフィットさせて解決した。

5キーワード復習

ターン制ストラテジー：自分と相手が交互に行動する戦略ゲーム形式。
タワーディフェンス：拠点を守って攻め寄せる敵を防ぐジャンル。成金大防衛もこの系統。
ドット絵（ピクセルアート）：四角いドットの集まりで描く絵。今回はコードで生成。
BFS：幅優先探索。近いマスから順に広げて到達範囲・最短経路を求める。
チェビシェフ距離：縦横斜めを同じ1歩と数える距離。範囲判定に使用。
ヒューリスティック：最適解でなく「だいたい良い手」を選ぶ簡易ロジック。敵AIに採用。
CI/CD・GitHub Actions：プッシュをきっかけに自動でビルド・公開する仕組み。
レスポンシブデザイン：画面幅に応じてレイアウトを切り替える設計。@mediaで実装。
