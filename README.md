# 暗号大戦線 — CIPHER FRONT

**AI戦・電子戦・暗号戦**をテーマにした、ドット絵のターン制グリッド戦略ゲーム。
スマホ向け戦略SLG「成金大防衛 / 成金大作戦」の "拠点を奪って資金を稼ぎ、ユニットを量産して敵首都を制圧する"
というコア設計を下敷きに、戦場をネットワーク／サイバー空間へ置き換えてリデザインした作品です。

依存ライブラリゼロの **単一HTMLファイル**。`index.html` をブラウザで開くだけで遊べます。

```
# ローカルで開く
open index.html        # macOS
xdg-open index.html    # Linux
# もしくは簡易サーバ
python3 -m http.server 8000   # → http://localhost:8000
```

## 遊び方

青の自律防衛AIを指揮し、ネットワーク上の**サーバー拠点**を奪って演算リソース **CP** を稼ぎ、
ユニットを量産して敵中枢AI **「KRONOS」** を制圧すれば勝利。自軍中枢コアが陥落すると敗北です。

1. **拠点を選択**して CP でユニットを生産
2. ユニットを**クリック→移動先をクリック**で行動。移動後にメニュー（攻撃／占拠／復号／暗号化／待機）
3. 敵を射程内でクリックすると攻撃。地形・相性・電子戦で威力が変動
4. **ターン終了**で敵AIフェイズへ。毎ターン拠点数に応じた CP 収入が入る

## 3つの戦域メカニクス

| テーマ | ユニット | 効果 |
|--------|----------|------|
| **AI戦**   | AIドローン | 地形・壁を無視して飛行する高火力の切り札 |
| **電子戦** | 電子戦機（ジャマー） | 周囲2マスの敵の攻撃力と機動を低下させる妨害フィールド |
| **暗号戦** | クラッカー | 敵拠点を**復号(ハッキング)**して占拠可能にし、自拠点を**暗号化**して防御 |

> 敵中枢AI「KRONOS」は **3重に暗号化** されている。クラッカーで復号 (Lv3→0) してから、
> ボットで占拠せよ。自軍コアもクラッカーで暗号化すれば敵の占拠を防げる。

## ユニット一覧

| ユニット | 種別 | コスト | HP | 攻撃 | 移動 | 射程 | 特徴 |
|----------|------|-------:|---:|----:|----:|----:|------|
| ボット | 軟 | 100 | 100 | 35 | 3 | 1 | 拠点を占拠できる主力 |
| ワーム | 軟 | 250 | 100 | 55 | 5 | 1 | 高機動。支援機を狩る一撃離脱 |
| ファイアウォール | 装甲 | 340 | 150 | 55 | 2 | 1 | 重装甲の防壁。中継ノードで鉄壁 |
| 電子戦機 | 支援 | 300 | 90 | 30 | 3 | 2 | 電子戦フィールドを展開 |
| クラッカー | 電脳 | 320 | 90 | 45 | 3 | 2 | 復号・暗号化を行う暗号戦ユニット |
| AIドローン | 飛行 | 520 | 110 | 75 | 5 | 1 | 飛行する高火力の切り札 |

種別ごとに攻撃相性があり（例: 飛行は支援に強い、電脳は装甲に強い）、地形防御と
電子戦の妨害が加味されてダメージが決まります。

## 技術メモ

- Canvas 2D によるプログラム生成のドット絵（外部アセットなし）
- BFS による移動範囲、ダイクストラ風の経路復元
- 簡易ヒューリスティックの敵AI（生産・攻撃評価・拠点占拠・コアへの前進）
- スキャンライン／ジャミングのフリッカー等のレトロ演出
